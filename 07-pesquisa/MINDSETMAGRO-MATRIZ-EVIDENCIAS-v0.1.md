# MINDSETmagro™ — Matriz de Evidências v0.1

**Status:** pesquisa; não altera cânone sem revisão autoral.

## Regra

Separar sempre:
1. conceito autoral;
2. mecanismo psicológico/comportamental vizinho;
3. nível de evidência;
4. limite da inferência;
5. uso pedagógico permitido.

| Conceito MINDSETmagro | Paralelo científico | Uso |
|---|---|---|
| Caos mental | ruminação / repetitive negative thinking / carga cognitiva | observar, externalizar, interromper loops; não diagnosticar |
| Sala de Controle | metacognição / decentering / autorregulação | metáfora pedagógica |
| Antifuga identitária | self-concept clarity / valores / identidade comportamental | recuperar autoria sem congelar identidade |
| Reposicionamento | autonomia / ação orientada por valores / autorregulação | converter insight em escolha |
| SE → ENTÃO | implementation intentions | gatilho + resposta observável |
| Frutos | self-monitoring / feedback | resultado como dado, não culpa |
| Nova Semente | action planning / habit substitution | substituir prática no contexto |
| Visualização de processo | mental imagery / episodic future thinking | ensaio concreto, não “manifestação” |
| Contraste Real | mental contrasting | desejo + obstáculo + plano |
| Diário Vivo | self-monitoring / cognitive offloading | registro para detectar padrões |
| Movimento Possível | graded action / redução do tudo-ou-nada | menor ação útil |
| Arquitetura da Escolha | choice architecture / fricção contextual | facilitar opção desejada |
| Mindful eating | atenção interoceptiva / mindfulness | consciência; não prometer cura de compulsão |
| MMI ampliado | body functionality / self-concept | aparência opcional + função + cuidado |

## Afirmações proibidas sem estudo do pacote completo

- “cientificamente comprovado”;
- “validado pela neurociência”;
- “reprograma seu cérebro em 30 dias”;
- “instala definitivamente um hábito”;
- “detox elimina toxinas acumuladas”;
- “um alimento é literalmente um prato de açúcar”;
- “visualizar faz o cérebro acreditar que já aconteceu” como explicação causal total;
- diagnóstico individual por IA.

## Saúde

Conteúdos de alimentação, exercício, suplementos, jejum e condições clínicas devem ter revisão específica por fonte de alta qualidade e aviso de escopo.

## Validação futura sugerida

0. congelar versão, público, dose e desfechos;
1. teste de compreensão/usabilidade;
2. piloto prospectivo;
3. comparar indicadores pré/pós sem prometer causalidade;
4. follow-up 30/60/90;
5. revisão de efeitos adversos: rigidez, culpa, ruminação, estigma de peso, hiperautovigilância, dependência da IA.
