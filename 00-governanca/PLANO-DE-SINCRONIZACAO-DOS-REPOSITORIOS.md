# PLANO DE SINCRONIZAÇÃO DOS REPOSITÓRIOS

**Objetivo:** impedir duplicação silenciosa, versões concorrentes e perda de contexto entre `universo-relacione-se`, `trilogia-sol-lima`, `Magnetus3` e `biblia-magnetus`.

## 1. Regra

O Universo Relacione-se mantém o **mapa e a governança transversal**. Repositórios especializados mantêm a implementação/cânone detalhado de seus domínios.

## 2. Quando uma decisão nasce em outro repositório

Registrar aqui:
- data;
- fonte;
- status;
- impacto no universo;
- arquivos dependentes;
- necessidade de atualizar marca/IA/produtos.

## 3. Quando uma decisão nasce aqui

Se afetar domínio especializado:
- Posicione-se/trilogia → sincronizar com `trilogia-sol-lima`;
- Magnetus/Antídoto/LÚCIDA → sincronizar com `Magnetus3`;
- cânone conceitual Magnetus → reconciliar com `biblia-magnetus`.

## 4. Tipos de cópia

### Cópia canônica integrada
Para definições transversais necessárias ao universo.

### Snapshot
Para registrar estado de uma fonte em determinada data.

### Ponte/referência
Quando duplicar o conteúdo aumentaria risco de divergência.

### Artefato
PDF, imagem, vídeo e renderização. Nunca substitui sozinho a fonte estruturada.

## 5. Checklist de sincronização

Antes de encerrar uma grande rodada de trabalho:
- [ ] nova decisão registrada no repositório de origem;
- [ ] impacto transversal registrado no Universo Relacione-se;
- [ ] versão antiga classificada;
- [ ] LÚCIDA apontando para versão correta;
- [ ] mapas/produtos atualizados;
- [ ] branding afetado revisado;
- [ ] pesquisa/evidência separada de cânone;
- [ ] artefatos listados;
- [ ] README/START-HERE coerente;
- [ ] nenhuma definição histórica tratada como vigente por acidente.

## 6. Cadência recomendada

- **a cada decisão autoral importante:** sincronização imediata;
- **a cada versão de produto:** auditoria de impacto;
- **antes de PDF/publicação:** congelamento de snapshot;
- **antes de treinamento/runtime LÚCIDA:** validação de fontes e precedência;
- **trimestralmente ou por grande lançamento:** auditoria completa de deriva semântica.

## 7. Regra final

> **Uma ideia pode nascer em qualquer lugar. A verdade operacional precisa terminar com endereço, versão e precedência claros.**
