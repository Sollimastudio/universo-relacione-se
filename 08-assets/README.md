## 2. Símbolo principal

**Cajueiro de Pirangi estilizado com cajus.**

Regras:
- não trocar por árvore genérica quando representar origem do método;
- caju deve ser legível no infográfico completo;
- versão simplificada pode reduzir quantidade de frutos;
- raízes podem sugerir rede/consciência, mas não substituir o cajueiro por um cérebro literal.

## 3. Símbolo secundário

Árvore + raízes com leitura neural/cerebral, inspirada na referência enviada pela autora.

Usos:
- LÚCIDA;
- inteligência;
- metacognição;
- ícone de raciocínio;
- ciência comportamental;
- mapas de investigação.

## 5. Regra para regeneração

Antes de gerar arte nova:
1. confirmar qual entidade está sendo representada;
2. verificar se é Relacione-se, Posicione-se, Magnetus, Antídoto ou LÚCIDA;
3. usar o símbolo correspondente;
4. manter filiação visual ao Cajueiro-matriz;
5. não inventar fruto diferente do caju em peças de origem do método;
6. conferir terminologia vigente;
7. revisar texto manualmente depois de geração visual por IA.
